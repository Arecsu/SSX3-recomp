# ssx3-recomp

Static recompilation of **SSX 3** (original Xbox, PAL) to a native Windows
executable with [xboxrecomp](https://github.com/sp00nznet/xboxrecomp), plus a
byte-exact per-function disassembly for hand decompilation.

Current state: boots and renders the game's own loading screen.

![loading screen](docs/screenshots/04-loading-screen-plain-run.png)

No game data or game code is in this repository. You need your own rip of the
disc (`default.xbe` + `data/`) next to this repo in `../SSX3/`; everything
derived from it is regenerated by `scripts/regen.sh`.

```bash
scripts/setup.sh                 # toolkit clone (pinned + patched) and Python venv
scripts/regen.sh                 # analysis, decomp/ split, src/recomp/gen/ C lift
scripts/sync-windows.sh --game   # copy to C:\Code\Xbox for the MSVC build
```

Build and run instructions, the bring-up history and the debugging workflow
are in [CLAUDE.md](CLAUDE.md).
